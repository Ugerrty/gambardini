# gambardini

Сайт мастерской премиальных аксессуаров для дома: латунь, мрамор, орех.
Итальянский стиль, московское производство.

- Статический сайт: HTML + CSS + JS, без сборки
- 3D: Three.js (matcap-материалы — работает даже на слабых GPU)
- Анимации: GSAP + ScrollTrigger, плавный скролл — Lenis
- Локальный запуск: `powershell -ExecutionPolicy Bypass -File serve.ps1` → http://localhost:4174/

Онлайн: https://ugerrty.github.io/gambardini/
